# Vantage UI + E2E Quality

1. Inspect current routes/components/styles first.
2. Reuse existing UI primitives.
3. Use frontend-design guidance without replacing Vantage's visual language.
4. Test desktop plus relevant tablet/mobile layouts.
5. Use Playwright for committed E2E coverage.
6. Use @axe-core/playwright for accessibility automation.
7. Use Playwright MCP for exploratory browser testing when useful.
8. Test keyboard navigation, focus, labels, errors, loading/empty states and permission-denied states.
9. Charts require accessible alternatives.
10. Report actual tested routes/scenarios in the handoff.
