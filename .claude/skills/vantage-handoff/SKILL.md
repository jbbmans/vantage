# Vantage Handoff

End every implementation response with:

- Task and status
- Repository / branch / commit reviewed
- Files/code inspected
- Files changed
- Exact existing Vantage code reused
- External source/package provenance
- Database/migrations
- Configuration/environment changes
- Tests and results
- Security/permission impact
- MCEN/deployment impact
- Known risks
- Remaining work
- Recommended next task
- Rollback/recovery notes

Never claim Complete if required tests were skipped or failed.
