# Vantage Reference Code Discipline

1. Search the authoritative repository/source, not blogs or model memory.
2. Record repository URL plus commit/tag/version used.
3. Verify license and compatibility before adoption.
4. Use official APIs and source behavior exactly for the selected version.
5. Do not invent APIs.
6. Prefer package/API use to copying source.
7. If source is copied, copy only the necessary portion and preserve license/NOTICE requirements.
8. Never wholesale-copy another application's architecture.
9. Vantage's current code is the primary reference.
10. Record external-code decisions in the handoff.
